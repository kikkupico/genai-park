Drop the pack, keep the dogThe transformer

Attention Is All You Need (2017)

Before this

The 2014 walker had a dog for the source road but still carried a pack along its own, and that pack forced training to go one step at a time. The transformer was designed for translation and for speed: keep the dog, give it the walker's own road as well, and drop the pack entirely.

The 2014 models used attention over the source but kept a recurrent decoder, and recurrence forced sequential computation during training. The transformer was designed for translation and for training speed: use attention for all interactions, including within each sequence, and remove recurrence.

Formally: compute \(p_\theta(x_t\mid x_{<t})\) for every \(t\) without any recurrence \(h_t = f(h_{t-1}, x_t)\), so that all positions of a training sequence can be computed in parallel.

In the walk

The walker carries nothing at all. Before every step it sends its dog back down its own road. The dog sniffs every footprint and runs back, and only then does the walker step. One footprint later, the dog goes again. This is why these models take the whole input again for every word: the road is the only memory there is.

In the mechanism

No state passes between steps. Each new token is computed from all the tokens before it through self-attention. A transformer runs many dogs at once, each with its own nose (heads), in several relay rounds (layers). Each round adds what it finds to what came in rather than replacing it, a residual connection borrowed from image recognition (Deep Residual Learning for Image Recognition, 2015); that is what lets dozens of rounds stack without training breaking down. It also caches each footprint's scent so later runs go faster, but every run still covers the whole road.

\[\operatorname{Attention}(Q,K,V) = \operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}} + M\Big)V,\qquad h^{(\ell+1)} = h^{(\ell)} + F_\ell\big(h^{(\ell)}\big)\]

No state passes between positions: position \(t\) sees \(x_{\le t}\) only through attention, and the mask \(M\) (\(-\infty\) above the diagonal) blocks the future. Many heads run in parallel per layer, and dozens of layers stack because each adds to its input, schematically \(h + F(h)\): the residual connection from image recognition (Deep Residual Learning for Image Recognition, 2015). At inference each token's keys and values are cached, but each new token still attends over the whole context.

Why give up the pack? Training speed. With no pack, every footprint of a training text can send its dog at the same moment, so a whole text trains in parallel, and the field could finally train on enormous amounts of text. Two rules keep it honest: the dog forgets after each run (otherwise it would be a pack again), and it runs only back, never ahead of the walker.

Why remove recurrence? Training parallelism. Under a causal mask, every term of \(\mathcal{L}(\theta) = -\sum_t \log p_\theta(x_t\mid x_{<t})\) is computed in one parallel pass over the sequence, which made training on much larger corpora practical. No state is carried between positions except the tokens themselves.

A closer look: what the nose actually doesscaled dot-product attention

Every footprint, when the dog reaches it, offers two things: a scent (key), saying what kind of thing is here, and a parcel (value), the information the dog would carry back. The dog sets out with a question (query) from the spot where the walker stands. At each footprint it compares question to scent; the better the match, the more of that parcel it brings home. In symbols, weights = softmax(q · k / √d), and the report is the weighted sum of the values.

A few details make it work:

  • Many dogs. The base model ran eight noses side by side in each round, each learning to ask a different question: one might track who is doing what, another what the last noun was.
  • Relay rounds. Six rounds in the original, each one's report added onto what came in. Later rounds work with what earlier dogs already brought back.
  • Footprint numbers. Scent alone doesn't say where on the road a footprint is, so each footprint is stamped with its position before the dogs set out.
  • No running ahead. During training the whole text is present, so the dog is masked from every footprint beyond the walker. Without that the model could simply copy the answer.

The cost is in the figure: every new word sends the dog over the whole road, so attention cost grows with the square of the road's length. Caching the scents and parcels saves recomputing them, but every run still visits each one.

The original model beat existing translation systems on English–German and English–French while training in a fraction of the time; the large version trained for 3.5 days on eight GPUs.

Each token's representation is projected into a query, a key and a value, \(q = W^Q h\), \(k = W^K h\), \(v = W^V h\). A token's output is a weighted sum of the values of the tokens it attends to, with weights given by how well its query matches each key:

\[\operatorname{Attention}(Q, K, V) = \operatorname{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V\]

Dividing by \(\sqrt{d_k}\) keeps the dot products from growing with dimension and saturating the softmax. The rest of the architecture:

  • Multi-head attention. \(\operatorname{MultiHead} = \operatorname{Concat}(\text{head}_1,\dots,\text{head}_h)\,W^O\), with \(\text{head}_i = \operatorname{Attention}(QW_i^Q, KW_i^K, VW_i^V)\). The base model uses \(h = 8\) heads per layer, so different heads can capture different relations.
  • Layers. Six layers each in the original encoder and decoder. Each sublayer, attention or a position-wise feed-forward network, is wrapped as \(\operatorname{LayerNorm}(x + \operatorname{Sublayer}(x))\).
  • Positional encodings. Attention is permutation-invariant, so \(PE_{(pos,2i)} = \sin(pos/10000^{2i/d})\) and \(PE_{(pos,2i+1)} = \cos(pos/10000^{2i/d})\) are added to the input embeddings.
  • Causal masking. In the decoder, \(M_{tj} = -\infty\) for \(j > t\), so training on full sequences doesn't leak the targets.

Self-attention costs \(O(n^2 d)\) for sequence length \(n\). At inference, caching each token's keys and values (the KV cache) avoids recomputing them, but each new token still attends over all previous ones.

The model set new state-of-the-art results on WMT 2014 English–German and English–French translation at a fraction of the training cost of earlier systems; the large model trained for 3.5 days on eight GPUs.

What it changed

Almost everything after this point is a transformer: the GPT series and BERT for language, vision transformers for images, and the networks inside many diffusion painters. Its advantage was less about seeing better than about training faster. With no pack, a whole text trains in parallel, and that is what made the scale of the next three entries possible.

Nearly every later model in this guide is a transformer: GPT and BERT for language, the Vision Transformer for images, and the denoising networks in many diffusion models. Its main advantage was trainability at scale rather than modelling power alone, and that parallelism made the scaling of the next entries possible.

Left open

The walker can now see its whole road, and it can be trained on almost anything written.
